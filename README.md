# Конвертер из DOCX в HTML (с формулами)

Простой скрипт на Python, который берет обычный файл `.docx`, парсит его внутренности (текст, таблицы, списки, картинки) и превращает всё это в одну чистую HTML-страничку. 

Главная фишка — он умеет вытаскивать вордовские формулы (OMML) и переводить их в нормальный MathML, чтобы они красиво отображались в любом браузере через MathJax.

---

## Что нужно для работы

1. **Python 3** (желательно посвежее).
2. Установленная библиотека `lxml` (без неё XML-дерево ворда не пропарсить и формулы не сконвертировать). Ставится одной командой:
   ```bash
   pip install lxml
